> Files are generated by `scripts/generate_documents.py`. Everything here is fictional. Before publishing, check that the company, supplier and carrier names do not match real businesses.

## Company

**Lantern Lane Goods** — an online home goods store.

- 14 staff: 2 owners, 5 customer service (CS), 3 operations, 2 marketing, 1 bookkeeper, 1 buyer.
- Sells furniture, textiles and home decor. Ships to the US and Canada only.
- Store on Shopify. Files in one shared cloud folder that has grown since 2023.
- Uses a paid AI assistant. Staff ask it policy and supplier questions instead of asking the owners.

## Planted problem types

| Code | Problem | Why it is realistic |
|---|---|---|
| V | Old version not deleted | "v2", "FINAL", "final2" all in the same folder |
| C | Two current files contradict each other | A policy changed but the CS macros or FAQ did not |
| S | Answer only in a spreadsheet | Rates and sales figures live in .xlsx |
| F | Scanned PDF with no text layer | Signed contracts are usually scans |
| D | Draft looks like policy | Proposals saved next to approved documents |
| X | Answer not in any file | Staff ask things the files never cover |
